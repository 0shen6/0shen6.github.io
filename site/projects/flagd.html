Flagd

A pixel-art minesweeper roguelite in C++20 and raylib, where the numbers show nearby monster power.

  • C++20
  • raylib 5.5
  • CMake + Ninja
  • MSYS2 UCRT64
  • doctest
View on GitHub Build it
01.

Overview

Flagd is a minesweeper roguelite. Instead of counting mines, each number on the board shows the total power of the monsters around it, so reading the board decides which fights you take and which you avoid.

02.

Gameplay

  • 3 acts, 3 bosses

    A run spans three acts, each ending in a boss.

  • Branching map

    Routes are picked on a Slay-the-Spire-style map.

  • Board twists

    Boards change the rules:

    • wrap-around
    • hex
    • fog
    • liars

05.

Build

In an MSYS2 UCRT64 shell:

ucrt64 ~/Flagd
# GCC, CMake and Ninja for UCRT64
pacman -S --needed mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-cmake mingw-w64-ucrt-x86_64-ninja

# configure and build (doctest is fetched on the first configure)
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build

# run
./build/flagd.exe

# tests
ctest --test-dir build
